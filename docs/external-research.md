# 외부 조사 넘겨주기

AskCode는 웹을 찾지 않는다(읽기 전용, 외부 전송 도구 없음). 질문에 외부 조사가 필요한 부분이 있으면 거절하는 대신 **사용자가 다른 AI에 붙여넣을 프롬프트**를 만들어 준다. 붙여넣을지는 사용자가 정한다.

## 동작

| 질문 | 처리 |
|---|---|
| 일부만 외부 조사 ("의원 뉴스 개발 가능할까? 외부 리서치도") | 코드·문서 부분은 평소대로 답하고, 답 아래에 🌐 외부 조사 프롬프트를 붙인다 |
| 전부 외부 조사 ("다른 서비스는 어떻게 해?") | `kind: external` → 에이전트 없이 🌐 안내와 프롬프트만 |
| 되묻기(broad) | 되묻기 버튼 아래에 프롬프트를 붙인다 |
| 개인정보·비밀값 요청(out_of_scope)·미지원 작업 | 프롬프트를 만들지 않는다 |

"이 기능 개발 가능할까" 같은 실현 가능성 질문은 `broad`가 아니라 `multi_hop`으로 분류하도록 스코핑 프롬프트에 적었다.

## 만드는 방법 (추가 모델 호출 없음)

1. 스코퍼(소형 모델)가 JSON의 `external: {goal, topics}`에 조사 목적과 질문 1~5개를 일반 한국어로 낸다. 출력 토큰이 수십~100개 늘어난다.
2. `pipeline/external.py`가 고정 템플릿으로 프롬프트를 만든다. 첫 줄은 사람이 쓴 `repos.yaml`의 `public_summary`다(사외로 나가므로 공개해도 되는 말만 쓴다).
3. **결정적 유출 필터**가 항목 단위로 걸러 낸다. 걸린 항목은 빼고 개수를 `scope.reason`(감사 로그)에 남긴다.
   - 모양: URL, `/api/...` 같은 라우트, 소문자 경로(`apps/api`), 파일 확장자, `Class.method`, camelCase, snake_case, kebab-case, 백틱
   - 이름: 구조 인덱스(API·라우트·manifest·브리지)의 key·label 조각(5자 이상, 일반 단어 제외), 레포 이름, `external_blocklist`
   - 조사 질문이 모두 걸리면 프롬프트 없이 "내부 정보가 섞일 수 있어 만들지 않았어요"만 안내한다.
4. 에이전트에는 외부 조사 항목을 알리고 "답하지 말고, 일반론·추정 단락이나 '외부 자료를 조회하지 못했다'는 말도 쓰지 말라"고 지시한다(`EXTERNAL_AGENT_NOTE`). 이 지시가 없을 때 에이전트가 근거 없는 일반론 단락으로 빈칸을 메웠다.
5. 지시해도 첫 줄·"확인 필요"에 "외부 리서치는 다루지 않았어요" 같은 메타 문장이 남아(q29 3차 실측), 프롬프트가 붙은 답에는 결정적 후처리 `strip_external_meta`를 건다. "외부 리서치·외부 조사", "외부 자료·웹 … 조회/찾지/못" 문장만 지우고, "확인 필요"는 쉼표 항목 단위로 뺀다. "외부 신호 수집", "외부 링크", "외부 영상" 같은 코드 개념과 🔧 줄은 건드리지 않는다.
6. 스코핑 JSON이 깨지면 한 번 더 묻는다(약 $0.003). 깨진 채로 범위 없이 대형 에이전트로 가면 q29 실측 환산 $0.84가 들었다. 한국어 JSON은 토큰이 많아 external까지 채우면 1,400토큰을 넘으므로 한도를 2000으로 올렸다(API 모드에서 잘림 방지, 구독 모드는 한도를 무시한다).

필터는 한국어 내부 용어(미공개 기능명 등)까지는 잡지 못한다. 그래서 슬랙 안내에 "붙여넣기 전에 내용과 사내 외부 AI 사용 정책을 확인해 주세요"를 붙인다. 막아야 할 한국어 용어는 `external_blocklist`에 넣는다.

## 확인

- 테스트: `tests/test_external.py` (필터 오탐·누락, 경로별 동작, 슬랙 블록)
- 실제 law-watch 구조 인덱스(500개 이름)로 조사 질문 예시 8개를 돌려 오탐 0건 확인
- 골든 세트 q29(일부 외부 조사 질문)
  - 1차 eval: 스코핑 JSON 깨짐 → 범위 없이 탐색, 프롬프트 없음(그래서 재시도 추가). 판정 ❌은 정답 쪽 누락(편집 정책) 때문이라 정답을 고쳤다.
  - 2차 `askcode ask`(구독 모드, 환산 $1.06·28초): 범위 people·ingestion, 프롬프트 5문항 첨부, 제외 0건. 답은 네이버 뉴스 수집기·승인 매체·제품 정의서 초기 제외를 근거로 했다. 이때 일반론 단락이 섞여 4번 지시를 추가했다.
  - 3차 `askcode ask`(환산 $1.05·26초): 일반론 단락은 사라졌지만 첫 줄·확인 필요에 메타 문장이 남아 5번 후처리를 추가했다. 3차 답변 저장분에 후처리를 적용해 두 문장이 빠지는 것을 확인했고, 후처리를 넣은 뒤 다시 돌리지는 않았다.
  - 슬랙 표시는 아직 확인하지 않았다.
