# AskCode 웹 콘솔 기획

2026-10-15 초안. 상태: **v1(R1~R7) 구현 완료(2026-10-16)**, P1·P2는 미구현. 실행: `uv run askcode console` → http://127.0.0.1:8787

## 한 줄 요약

슬랙 답변은 흘러가 사라지고, 같은 질문이 반복된다. 웹 콘솔은 AskCode의 답을 **다시 찾아 쓰는 기획자용 지식 창고**이고, 동시에 **봇을 점검·개선하는 운영 도구**다.

![웹 콘솔 홈: 검색, 이번 주 질문·비용, 확인 필요, 최근 답](screenshots/web-console-home.webp)

*홈 화면(2026-10-16). 검색창과 필터, 이번 주 질문(경로별)·비용·확인 필요 건수, 최근 답 목록(경로·인증 경로·확신도·도메인 칩, 비용). Cloudflare Tunnel + Access 뒤에서 팀에 공개한 주소로 연 모습.*

## 가정

기획 질문 세 가지에 답을 받지 못해 아래처럼 가정했다. 다르면 이 절부터 고친다.

| 질문 | 가정 |
| --- | --- |
| 1차 목적 | 기획자의 재사용 + 파일럿 운영. 면접 데모의 "평가·비용" 장면에도 쓴다 |
| 사용자 | 기획자와 운영자·개발 리드. **모든 질문과 답은 팀 전체에 공개**한다(2026-10-16 결정) |
| 배포 | v1은 로컬 전용(localhost). 파일럿 때 VPS + 로그인 |

## 1. 문제

**기획자의 문제**
- 슬랙 스레드는 시간이 지나면 찾기 어렵다. "지난주에 누가 물어봤던 푸시 시각 답"을 다시 찾으려면 슬랙 검색을 뒤지거나 봇에게 다시 묻는다.
- 같은 질문을 다시 물으면 비용과 시간이 또 든다. 실측 기준 심층 탐색 1건은 약 $0.05, 15~30초다.
- 표현만 다른 같은 질문이 이미 생긴다. 예: "구독은 한 사람이 몇 개까지…" / "구독은 최대 몇 개까지…".
- 답은 특정 커밋 기준이다. 코드가 바뀐 뒤 옛 답을 그대로 믿으면 틀린 기획이 된다. 지금은 그 답이 아직 유효한지 알 방법이 없다.
- 와이어프레임·흐름도·변경안 목업이 스레드에 흩어져 있어, 기획서에 붙이려면 다시 찾아야 한다.

**운영자의 문제**
- 확신도 낮은 답, 👎, 확인 요청, 오류를 한곳에서 보지 못한다. 지금은 `askcode stats` 몇 줄과 SQLite 직접 조회뿐이다.
- 나쁜 답의 원인(스코핑·검색·생성)을 가르려면 DB와 로그를 직접 뒤져야 한다. 오늘 실제로 그렇게 진단했다.
- 비용이 어디서 늘었는지 매번 계산해야 한다.

## 2. 목표

| # | 목표 | 측정 |
| --- | --- | --- |
| G1 | 기획자가 이미 답한 질문을 **30초 안에** 다시 찾는다 | 콘솔 검색 → 답 상세 열람까지 걸린 시간 |
| G2 | 반복 질문을 줄인다 | 파일럿 3주 동안 슬랙에서 비슷한 질문이 새로 처리된 비율(비슷한 답이 이미 있었는데도 새로 처리된 비율) |
| G3 | 옛 답을 잘못 믿는 일을 막는다 | 근거 코드가 바뀐 답 중 "다시 확인 필요" 표시가 붙은 비율 100% |
| G4 | 운영자가 나쁜 답의 원인을 **한 화면에서 2분 안에** 분류한다 | 질문 상세 하나로 실패 단계(스코핑·검색·생성)를 판단 |
| G5 | 데모 "평가·비용" 장면을 화면 2개, 1분 안에 보여 준다 | 리허설에서 확인 |

## 3. 하지 않는 것

| 항목 | 이유 |
| --- | --- |
| 콘솔에서 새 질문하기(채팅) | 질문 창구는 슬랙 하나로 둔다. 창구가 둘이면 기록이 갈라진다. 다만 "최신 코드로 다시 묻기"는 P1로 둔다 |
| 답변 수정·삭제 | 감사 로그는 append-only다. 정정은 "메모"로 덧붙인다 |
| 코드 뷰어 | 근거는 GitHub 링크로 연다. 코드를 콘솔에 복제하지 않는다 |
| 봇 설정 편집(도메인 맵·프롬프트) | 설정은 레포 파일로 관리하고 리뷰를 거친다. 콘솔은 "고칠 후보"만 보여 준다 |
| 실시간 대시보드 | 새로고침으로 충분하다. 운영 규모가 작다 |

## 5. 요구사항

### P0 — v1 필수

**R1. 검색과 질문 목록**
- 질문·답변 전문 검색. 같은 질문의 다른 표현도 찾는다(형태소 수준 부분 일치. 한국어 2글자는 문서 검색과 같은 방식).
- 필터: 기간, 도메인, 경로(빠른 답·심층·와이어프레임·흐름도), 확신도, 피드백, 출처(슬랙·CLI·평가)
- 기본값: 출처는 슬랙만, 최신순. 평가·CLI 질문은 운영 필터에서만 본다.
- 수락 기준
  - [ ] "푸시 시각"으로 검색하면 "매일 받기로 설정하면 푸시가 아침 몇 시에 와요?"가 나온다
  - [ ] "구독 최대"로 검색하면 표현이 다른 두 구독 질문이 함께 나온다
  - [ ] 답변이 없는 질문(되묻기·거절·오류)은 구분 표시된다

**R2. 답 상세 (기획자 보기)**
- 질문, 답(슬랙과 같은 문체, 굵은 결론 → 목록), 근거(파일·문서 링크, 설명), 기준 커밋과 날짜, 확신도, 산출물, 피드백 수
- **최신성 배지**: 검증된 코드 근거 파일이 기준 커밋 이후 최신 동기화 커밋까지 바뀌었는지 비교한다(로컬 클론의 git, API 비용 없음)
  - ✅ 근거 변경 없음 / ⚠️ 근거 파일 n개 바뀜(파일 목록) / ❔ 비교 불가(근거 없음)
- 고정 링크(`/q/<id>`)
- 수락 기준
  - [ ] 근거 파일이 바뀐 커밋으로 동기화하면 그 답에 ⚠️가 붙고, 바뀐 파일 이름이 보인다
  - [ ] 근거가 없는 답은 ❔로 표시되고 "개발자 확인 권장"이 보인다

**R3. 질문 상세 (운영자 보기)**
- R2의 내용 + 스코핑 결과(유형·도메인·이유·범위 미스), 탐색 과정(도구 단계, 슬랙 "근거 전체 보기"와 같은 문장), 제외된 근거와 사유, 토큰(입력·캐시 재사용률·출력)·비용·시간·모델 호출 수, 피드백·후속 질문 클릭·확인 요청 이력
- 같은 페이지에 탭으로 둔다. 기획자 보기가 기본이다.

**R4. 확인 필요함 목록**
- 조건: 확신도 낮음 OR 👎 OR 확인 요청 OR 오류 OR 한도 도달 OR 범위 미스. 조건별 개수와 최근순.
- 수락 기준
  - [ ] 오늘 이런 질문이 0건이면 "확인할 것 없음"이 보인다
- 처리됨(2026-10-16 추가): `askcode resolve <id>`로 처리 기록을 추가하면 목록·건수에서 빠지고 "처리된 건 보기"로 옮겨 간다. 처리 뒤 새 👎·확인 요청이 오면 다시 열린다. 콘솔은 읽기 전용이라 버튼 대신 상세 화면에 명령을 보여 준다.

**R5. 평가 이력**
- `eval/results/*.json`을 회차별로 보여 준다: 정답률, 행동 일치, 근거 재현율, 비용, 시간
- 두 회차 비교: 문항별 새로 맞음·새로 틀림·그대로, 판정 이유
- 수락 기준
  - [ ] 2차(86%)와 1차(50%)를 비교하면 새로 맞은 문항 목록이 나온다

**R6. 공개 범위 안내**
- 팀 도구이므로 모든 질문·답은 팀 전체에 공개한다. "나만 보기"는 두지 않는다(권한 처리가 복잡해지고 재사용 가치가 줄어든다).
- DM은 사적인 대화로 오해하기 쉬우므로, 봇이 질문을 받을 때 처리 중 메시지에 "질문과 답은 팀 콘솔에 공개돼요"를 함께 보여 준다.
- 수락 기준
  - [ ] DM과 멘션 모두 처리 중 메시지에 공개 안내가 보인다

**R7. 보안·운영**
- 감사 로그 DB는 **읽기 전용 연결**로 연다(`mode=ro`). 콘솔은 감사 로그를 바꾸지 않는다.
- v1은 `127.0.0.1`에만 연다. 외부 CDN·폰트·스크립트를 쓰지 않는다(정적 파일 포함, CSP).
- 비밀값은 보여 주지 않는다(설정·토큰 화면 없음).
- 실행: `uv run askcode console` (기본 포트 8787)

## 8. 기술 방향

- 서버 렌더링(FastAPI + Jinja 템플릿), 빌드 단계 없음, 외부 리소스 없음. 이미 쓰는 Python·uv 스택 안에서 끝낸다.
- 감사 로그 SQLite를 읽기 전용으로 연다. 검색은 기존 문서 검색과 같은 FTS5 trigram을 질문·답 테이블에 붙이되, 콘솔 전용 색인 파일에 둔다(감사 로그 스키마를 바꾸지 않는다).
- 답 파싱(본문·근거·후속 질문·불일치)은 `pipeline/answer.py`의 함수를 그대로 재사용한다. 슬랙과 콘솔이 같은 결과를 보여야 한다.
- 콘솔은 Claude API를 호출하지 않는다. **실행 비용 0.** R13(다시 묻기)만 예외이며 비용을 먼저 보여 준다.
