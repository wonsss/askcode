### 시험하지 않았거나 주의할 것

- **"의안 목록이 웹이랑 앱에서 다르게 동작하나요?"** (q14): 2차 평가에서 웹 기본 페이지 크기(6건)를 빠뜨려 오답이었다. 페이지 번호와 무한 스크롤의 차이는 맞게 답하지만, 데모에는 넣지 않는 편이 안전하다.
- **스크린샷 역추적**: 슬랙에서 아직 시험하지 않았다. 넣으려면 리허설 때 먼저 확인한다.
- 같은 질문이라도 스코핑이 가끔 다르게 분류한다(q11이 되묻기로 간 적 있음). 리허설 결과와 다르면 버튼에서 범위를 고르면 된다.

## 라이브 데모 안전장치

- 심층 탐색은 15~30초 걸린다 → 2번(빠른 답)을 먼저 보여 체감 속도를 확보한다.
- 30초가 넘으면 미리 실행해 둔 스레드나 백업 영상으로 전환한다.
- 네트워크 문제 대비: 노트북에서 `uv run askcode ask "질문"`으로 같은 질문을 CLI로 보여줄 수 있다.
- 크레딧이 떨어지면 봇이 "지금은 AI 모델을 호출할 수 없어요"라고 바로 답한다. 데모 전에 `doctor --online`의 "Claude 호출" 항목을 확인한다.
- 데모 1회(Q1~Q6, 버튼 포함)는 약 $0.35다. 리허설까지 포함해 $1 이상 여유를 둔다.
