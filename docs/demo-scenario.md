# 데모 시나리오 (약 7분)

대상: [wonsss/law-watch](https://github.com/wonsss/law-watch) — Next.js 웹, Expo 하이브리드 앱(네이티브 + 웹뷰), NestJS API·워커 모노레포, 인덱싱 대상 약 3,260개 파일.

## 준비

- [ ] law-watch 최신 커밋을 GitHub에 푸시 → `askcode sync`
- [ ] 노션 문서 공유: 노션 「AskCode 데모 — law-watch 기획 문서」 페이지를 봇 통합에 연결 → `askcode sync`
- [ ] `askcode eval` 실행해 결과표 확보 (`eval/results/eval-*.md`)
- [ ] 아래 질문을 데모 채널에서 한 번씩 미리 실행(캐시 예열)
- [ ] 백업 영상 녹화

## 라이브 데모 안전장치

- 에이전트 경로 답변은 수십 초 걸릴 수 있음 → 2번(빠른 경로)을 먼저 보여 체감 속도 확보
- 20초 이상 걸리면 미리 실행해 둔 스레드나 백업 영상으로 전환
- 네트워크 문제 대비: 노트북에서 `askcode ask`로 같은 질문을 CLI로 보여줄 수 있음
